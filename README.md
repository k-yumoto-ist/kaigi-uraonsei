# 🎙️ 会議のウラ音声

架空の会社の会議を副音声と弾幕で観戦する、ブラウザ向けツッコミゲームです。

## プレイ

**GitHub Pages:** https://k-yumoto-ist.github.io/kaigi-uraonsei/

- 会議シナリオは3種類：組織再編、週次進捗定例、顧客提案レビュー
- 文脈に合わせた24カテゴリ・144種類のツッコミ
- 自由入力の弾幕、スコア、コンボ
- 発言の「ウラ音声」テキストとブラウザの音声読み上げ切り替え
- 皮肉の濃さを選択可能
- PC・スマートフォン対応

## 開発・公開

ビルドやサーバーは不要です。ルートの `index.html` をブラウザで開けば動作します。
`main` へのpushで `.github/workflows/deploy-pages.yml` が自動デプロイします。

**初回のみ：** GitHubリポジトリの `Settings → Pages → Build and deployment → Source` が **GitHub Actions** になっていることを確認してください。未設定の場合は選択してください。

## 移行について

以前のChatGPT Sites版からGitHub Pagesへ移行する目的で作成しました。ただし、元のSites版のソース一式はこの環境から取得できなかったため、直近の「文脈マッチング改修デモ」のソースをベースに再構成しています。元サイトの完全なバイト単位のコピーではありません。副音声表示・ブラウザ音声合成を追加しています。

## プライバシー

本アプリ内の会議・登場人物・発言はすべて架空です。録音・マイクの収集・サーバーへの送信は行いません。ブラウザのSpeech Synthesis APIで音声を生成します（対応ブラウザのみ）。
